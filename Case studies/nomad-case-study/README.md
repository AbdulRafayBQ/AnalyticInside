# Nomad Coffee Studio Case Study (AnalyticalInsider)
Independent concept, not affiliated with Nomad Coffee Studio. Reference: https://nomadcoffeestudio.com/
Open index.html in a browser (no build step). Internet is needed for the store product images and Google Fonts; without it, neutral bag/gear placeholder shapes show.
Stack: HTML5, CSS3 (CSS 3D), vanilla JavaScript. No frameworks, no 3D library.
Product images belong to Nomad Coffee Studio and are hot-linked; replace with licensed local files before public release.
