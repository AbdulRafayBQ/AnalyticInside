# Dalda Foods Case Study (AnalyticalInsider)
Independent concept, not affiliated with Dalda Foods Ltd. Reference: https://www.daldafoods.com/
Open index.html in a browser (no build step). Internet is needed for the official pack images and Google Fonts; without it, neutral pack-shaped placeholders show.
Stack: HTML5, CSS3 (CSS 3D), vanilla JavaScript. No Three.js, no frameworks.
Pack images belong to Dalda Foods Ltd and are hot-linked; replace with licensed local files before public release.
