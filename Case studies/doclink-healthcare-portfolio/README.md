## Project positioning
Pakistan-based healthcare startup built with React, Next.js, Redux and Material UI.

The case study highlights:
- 24/7 online doctor access
- Clinic appointment booking
- Specialist and condition discovery
- Subscription plans
- Lab tests and report workflows
- Responsive frontend architecture
- Scalable dashboard/product thinking
