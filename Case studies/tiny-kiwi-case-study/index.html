The brief

Eliminating canvas bottlenecks to deliver desktop-grade photo editing in the browser.

Web-based photo editors frequently suffer from severe frame drops and sluggish slider interactions as layers, filters and high-res assets accumulate. Tiny Kiwi needed to feel as responsive and buttery-smooth as a native desktop application, even on mid-tier laptops.

Elyven refactored the rendering architecture from the ground up: moving heavy pixel filtering into parallel Web Workers via OffscreenCanvas, and implementing a diff-based undo/redo snapshot system that cut memory consumption by 92%.

This case study uses portfolio-safe production screens and sanitized data. No confidential proprietary client information is displayed.

01Framerate Jump from 24 to 58 FPS

Virtual layer compositing ensures only visible elements in the current viewport are redrawn per frame.

02Non-Blocking Filter Pipeline

Heavy gaussian blurs and duotone filters calculate in background worker threads without freezing the UI.

03Under-50KB History Memory

JSON state diffs replace brute-force pixel snapshots, allowing hundreds of undo steps without memory leaks.

What it does

Engineered for absolute reliability at scale.

Every component, query and user interaction was designed to balance visual polish with raw performance.

01
Hardware-Accelerated Canvas

Optimized rendering loop taking advantage of GPU canvas context with sub-pixel text rendering.

02
OffscreenCanvas Web Workers

Multi-threaded filter computation isolating heavy matrix transforms from the user interface thread.

03
Diff-Based Undo/Redo Engine

Lightweight snapshot manager storing parametric state deltas rather than whole bitmap buffers.

04
Serverless Background Removal

Node.js edge API integration for automated AI-based foreground segmentation and matte extraction.

05
Virtual Layer Compositor

Intelligent viewport culling compositing only the active bounding boxes during active pan and zoom.

06
High-Resolution 300 DPI Export

Vector and raster export pipeline generating print-ready CMYK-compatible assets without resolution loss.
